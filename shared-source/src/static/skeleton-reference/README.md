# 本地骨架参考素材

这些图片裁切自用户本轮提供的分类、播放器及个人中心截图，用于本地页面布局参考。影片名称、会员、评分、观看记录及广告内容都是离线样式示例。真实内容由运营服务及客户端提供。

首页参考图 home-hero.jpg、home-poster-0..2.jpg 来自用户本轮截图，仅用于本地骨架样式预览。图片不代表 CMS 接口数据。

本轮 front-* 是首页，home-* 是电视剧分类；anime-*、movie-*、variety-* 各自用于分类。shortdrama-scene 和 player-scene 仅含画面区域，导航、按钮、标签及弹层使用 Vue 组件绘制。素材来源是用户截图裁切，非原始高清宣传图，不代表联网播放或 CMS 返回。
