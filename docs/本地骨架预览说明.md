# 手机骨架与安装包

主题中心手机画布恢复最后确认的 ReferenceSkeleton 设计，覆盖首页、分类、个人中心、短剧、播放器和一起看。分类页含轮播图、分类入口与海报内容列表；播放器保留选集、全部选集及推荐区域。详情等其他设计页使用 SkeletonPage。

画布使用仓库内的离线参考素材，示例影片、集数和房间仅展示设计效果。用户上传的轮播素材优先显示；分类独立外观、模块、排序与开关继续生效。交互预览可以进入播放器，选取编辑可以选择模块并调整外观。修改直接作用于当前草稿，不读取生产 CMS，也不连接打包器。

此前 v0.4.4 用 MobileExperience 替换参考画布造成视觉退回，本次撤销这一设计决定，保留该版本的数据控制器和离线安全修复。

独立客户端仍由 AppExperience / MobileExperience 读取真实目录、详情、播放线路和集数。恢复主题中心画布不等于 Android 渲染已同步；要让安装包呈现相同参考设计，需要另行修改客户端渲染并重编完整底包。主题 ZIP 只传递主题配置和素材，不能替换 APK 内的组件。

主题中心和打包器保持独立，主题通过用户手动导出、导入 ZIP 传递。品牌图形和页面外观遵循当前主题配置，桌面应用图标由打包器单独设置。投屏、同步房间和下载服务需要真实客户端能力，离线参考入口不表示业务已接通。
