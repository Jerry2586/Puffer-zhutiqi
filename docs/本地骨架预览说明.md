# 手机骨架与安装包

主题中心的手机首页、分类、个人中心、详情和播放器统一使用 shared-source/src/components/MobileExperience.vue，由 AppExperience 提供交互控制。打包器保存同一组件的版本化源码副本，编译进 Android 完整底包。主题中心保持离线，双方只通过用户手动导出的 ZIP 传递主题和素材。

离线画布显示主题布局、上传素材和空状态，不填充示例影片、虚构集数或会员信息。正式客户端通过配置的真实服务读取目录、详情、播放线路及集数，收藏和观看历史使用本机记录。播放、切换线路、选集、下一集与错误状态绑定真实控制器。

上传的品牌 Logo 用于页面品牌入口、个人中心及播放器水印；Android 桌面图标由打包器单独设置。详情页和播放页分别遵循各自的页面外观覆盖。

旧完整移动底包没有 mobile-experience-v1 能力标识时，打包器阻止继续打包并提示导入新底包。单纯重新导出主题不能替换旧 APK 中的渲染代码，必须使用重新编译的完整底包生成新的安装包。

未接入的投屏、同步房间和下载服务不显示伪操作入口。真实后端内容、账号权限与设备播放能力需要在对应环境验收。
