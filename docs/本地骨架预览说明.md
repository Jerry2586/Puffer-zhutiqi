# 本轮手机骨架本地预览

## 已实现

右侧画布中的首页、分类页、播放器及个人中心参考布局。首页采用全幅横向轮播、可横滑分类入口及三列海报，素材来自用户提供的参考截图。分类包含频道、横向轮播和三列海报；播放器包含控制层、投屏和一起看入口、详情、选集及广告位；个人中心包含会员卡、快捷入口和观看记录。选集、详情页切换、弹层和页面导航可在交互预览模式操作；选取编辑模式只选择样式分组。

## 当前交付范围

实现位于工作台 ReferenceSkeleton.vue，仅用于手机本地设计预览，未接入 APK 渲染器或导出包运行时。未实现真实播放、投屏设备发现、一起看房间同步、下载或会员服务。弹层明确提示服务接入状态；参考素材不代表实际运营数据。其他设备及页面保持既有实现。
