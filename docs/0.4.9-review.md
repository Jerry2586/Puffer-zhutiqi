# 0.4.9 发布审查记录

日期：2026-10-31。

## 修改前审查

从独立工作树核对 origin/main 的 97fc7aa 与已确认的桌面定稿，发现正式源码遗漏已定稿的渲染组件，同时活动配置校验与固定底座不一致。原始 zhutiqi、dabaoqi 工作区保留；定稿底座不重写。

## 修改后代码审查

主线程检查渲染入口、独立预览请求时序与卸载、分类范围、活动准备与只读查找、轮播绑定、短剧播放及资源释放、运营配置白名单、服务校验、构建来源、CI 和两端导入测试。审查与测试分别执行。

审查发现并修复：

- 排期 categoryId/categoryEntry 被运营预览白名单遗漏，导致分类越界。
- 合并运营数据时，排期和广告被错误注入 navigation/categories 的图标默认字段。
- 短剧选集面板残留手动线路按钮，与轮询播放器的既定职责冲突。

以上问题均加入或更新回归断言。最终差异执行 git diff --check。独立复核尝试因服务返回 429 未完成，未将其记为审查通过。AOCI 技能当前未提供，未声称已执行。

## 边界

UI 实现补齐正式来源，固定协议不随单个骨架改动；骨架库提供制作底座，编辑器提供主题导出。主题颜色、背景和图标属于主题层，运营绑定、内容和功能开关属于运营层；轮播不自动采集影片充数，短剧无手动线路 UI。

SVG 在主题中心经过净化；已发布打包器 0.7.5 不支持 SVG，交付检查必须如实失败。解析器、源码快照及导入通过不等于最终 APK/安装态/UI 或真实生产视频验收。
