# 河豚主题中心

Windows 独立主题制作软件，版本 **0.4.6**。本仓库用于主题中心源码、后续版本更新与程序发布。

## 直接使用

正式安装包与便携版从 GitHub Releases 下载。main 分支的 Actions 制品用于构建检查；版本标签通过检查后才发布正式附件：

- **Hetun-Theme-Center-0.4.6-x64-Setup.exe**：Windows 64位安装包，推荐日常使用。
- **Hetun-Theme-Center-0.4.6-x64.exe**：便携程序，无需安装开发环境。
- **SHA256SUMS.txt**：文件校验值。

当前为正式发布版本，Windows 程序尚未配置代码签名。安装和便携版都自带前端、主题服务和运行时，不需要用户安装 Node、uni-app 或 Electron。安装前关闭主题中心；覆盖安装保留已保存数据。两种程序共用本机主题数据，建议固定使用一种入口。

## 使用与职责

- 独立主题库，手机、平板、电视、网页骨架分别管理；安装某端骨架后才可编辑该端。
- 三栏编辑：页面与模块树、大尺寸可点击画布、可折叠设计属性。
- 品牌、轮播、卡片、导航外观、配色与节日装饰、品牌开机页。
- 主题改名、复制、删除、导入；草稿保存、撤销重做和带素材的 ZIP 导出。
- 本机制作无需登录或 Key；设置中的“运营中心连接”可按需读取已发布内容进行预览，未连接时显示真实空态。
- 独立骨架定义页面组件、顺序、可见性、间距与内容绑定；支持范围内的新排版直接导入，不需要改主题中心。

首次启动直接进入主题库，无需联网、账号或 Key。软件不连接授权终端、云端记录或在线更新服务。运营预览地址在设置中按需连接，只保留在当前会话；成品后台地址由打包器配置，主题导出不携带预览连接地址或旧后台配置。主题中心只设计外观，首页分类、底部导航名称/目标/CMS绑定、广告、会员、收费与功能开关归运营中心。编辑器实时展示当前主题效果；保存后导出主题 ZIP，再由用户在河豚打包器手动导入并生成 APP 原生安装包。

选择主题进入编辑器。左侧选页面或模块，右侧点“编辑”展开属性，画布立即响应。交互预览用于检查布局和页面跳转；连接运营中心后读取已发布分类、轮播、影片与播放列表，并每15秒刷新。未连接、空内容和错误按实际状态显示。选取编辑模式用于选择模块属性。Ctrl+S 保存，Ctrl+Z 撤销，Ctrl+Shift+Z 重做。切换主题保留本会话未保存草稿；关闭前应保存。

## 源码、环境与数据分离

仓库只存源码、构建配方、锁定文件和测试。共享客户端渲染器、主题协议及实际服务已纳入 **shared-source/**，下载本仓库即可构建，不依赖相邻桌面项目。它是受版本管理的源码快照，后续主题相关修改也要更新此目录。

默认目录：

| 内容 | 位置 |
|---|---|
| 源码 | 当前仓库 |
| 外部依赖、编译副本、成品 | %LOCALAPPDATA%/Programs/UniAppTools/projects/hetun-theme-center |
| 软件主题数据及运行日志 | %LOCALAPPDATA%/HetunThemeCenter |

不在源码目录执行 npm install 或存放证书、Key和运行状态。依赖安装脚本会把 Node 依赖安装到外部环境目录；主题软件自身运行不依赖该开发目录。更新时可先备份本机主题数据目录。

## 从源码构建

使用含npm的 **Node.js 22（npm 10）**。Windows 64位下，在仓库目录运行：

```
node scripts/setup.cjs
node --test tests/integration.test.cjs
node scripts/build.cjs
```

第一次 setup 会下载锁定的 uni-app 与 Electron 构建依赖。完整构建依次执行 Vue/TypeScript 检查、实际 H5 编译、真实本机主题服务启动与编辑检查，再生成便携包和安装包。

仅编译页面：node scripts/build.cjs --frontend-only。成品位置为外部环境下 release/v0.4.6/，latest-build.json 记录本次构建，release-info.json 和程序内构建信息记录版本与 Git提交。

可选环境变量：HETUN_TOOLS_ROOT、HETUN_THEME_BUILD_ROOT、HETUN_UNI_DEPS、HETUN_ELECTRON_DEV；这些目录必须在仓库外。HETUN_FILM_SOURCE 可显式指定另一份兼容共享源码；默认使用本仓库 shared-source。常规发布请保持默认，确保成品对应仓库代码。

测试默认使用仓库内实际服务与 tests/fixtures/license-server 中的真实授权协议服务。随机账号、签名密钥和测试状态仅生成在系统临时目录，不随软件打包。

## 后续更新发布

1. 修改源码，更新 package.json、工作台版本显示及说明文件。
2. 执行测试与构建，将相关源码提交到 main。
3. GitHub Actions 对 main 更新自动运行真实服务测试、前端类型检查及 Windows程序构建，可在 Actions 下载校验后的构建制品。
4. 需要发布成品时，创建与 package.json 一致的 v版本标签并推送；全部检查通过后自动发布 GitHub正式版本、安装包、便携包和校验文件。

正式版本附 SHA256 清单；是否具备 Windows 代码签名会在发布信息中明确标记。仓库更新不会自动覆盖本机程序；用户下载新安装包覆盖安装即可更新。运营中心服务器部署、应用商店发布及原生客户端构建各自独立。

0.2.5 修复：主题库与编辑器右上角日月按钮、窗口标题栏与工作台明暗同步并记忆选择；紫色快捷方式图标兼容 Windows 小尺寸显示并随启动校正。未保存退出确认、短窗口布局和既有主题数据保留。

## 0.2.10 全部离线（历史版本）

- 移除桌面 Key 激活、云端记录、公告同步和自动更新入口及运行链路。
- 本机服务拒绝 CMS、目录、播放、会员及授权接口；离线子进程阻断出站 HTTP、fetch 和 socket 连接。
- 页面使用同源 CSP，桌面窗口额外拦截非本机网络请求；远程素材保留为主题配置但不加载。
- 保留本机主题库、保存、复制、导入、带素材 ZIP 导出，以及多端主题协议说明。
- 更新通过手动运行新版本安装包完成。已有主题和素材继续使用；旧授权缓存与历史文件不再读取或上传，不自动删除用户文件。
- 本机服务使用 127.0.0.1 通信，这是电脑内部通信；软件日常使用不需要互联网。首次源码 setup 和正式制品发布仍需联网下载依赖或上传制品。

## 0.4.6 设置与独立骨架

骨架库提供“下载制作底座”和“安装骨架包”；“UI 设计”右上角保留“导出主题包”，导出 ZIP 后到打包器手动导入。“设置 → 运营中心连接”集中管理预览地址、连接状态、刷新和断开，不再提供重复的打包交付页面。返回 UI 设计保留当前分类与未保存草稿。两软件仍独立运行。

骨架定义使用 theme.skeleton.definition v1。新排版可以组合已有组件；新增组件能力仍需要升级共享运行时。包含独立骨架定义的主题必须配合实际支持 skeleton-definition-v1 的打包器与基础 APK；本次桌面发布不会自动升级打包器、旧底包或已安装 App。

## 原生端交接

导出的 hetun-skeleton v2 包包含 clientContract v1、OpenAPI 3.1，以及安卓手机/平板、Android TV、iPhone/iPad 和网页目标映射。主题包不设置运行后台地址；后台配置归打包器。原生 Kotlin/Swift 渲染器与打包器仍须按协议实现；软件本身的预览仍采用 Vue/uni-app，不代表已实现原生客户端。

完整说明见 [多端接入与打包协议](NATIVE-INTEGRATION.md)。

## 0.4.1 两个软件独立运行

主题中心独立制作并导出 ZIP；在打包器手动导入和选择主题。两端不自动连接或同步，不要求对方启动。保存只更新主题中心自身草稿；没有本机发布或成品主题预览服务，编辑器实时预览直接使用当前草稿。已保存主题与草稿保留。已移除本机发布按钮及相关提示，主题通过 ZIP 手动交接。

## 固定接口边界

主题中心只负责主题与素材，打包器负责协议基础 APK、版本、后台和签名。打包器在用户手动导入主题 ZIP 后，根据实际基础包声明检查兼容性；导出成功不等于主题可打包。完整接口与限制见 [固定接口协议](PACKAGE-CONTRACT.md)。新版 Android 基础包内置与本仓库对应的完整 Vue 客户端快照，包含短剧等页面；旧底包仍按实际能力拒绝不兼容主题，需要在打包器导入新版基础 APK 后重新出包。IPA/EXE 二进制重打包未接入。

## 0.4.0 UI 设计与单页编辑

骨架页面入口、单页模块编辑和右侧交互预览分别显示；进入单页仍保留上方主菜单。固定模块和自定义模块统一六种模板，各分类独立保存覆盖设置。手机参考骨架仅用于离线设计预览，新增样式仍须由实际基础 APK 支持才能打包。详细交付与验证范围见 RELEASE-NOTES.md 和 docs/R020-本地功能检查与故障修复记录.md。
